Imersão Dados Python - Alura 📊
Repositório dedicado ao projeto desenvolvido durante a Imersão Dados da Alura. O foco principal foi a análise exploratória de dados utilizando Python e bibliotecas de Data Science para extrair insights valiosos de conjuntos de dados reais.

🚀 Tecnologias Utilizadas
Python (Linguagem base)

Pandas (Manipulação e tratamento de dados)

Matplotlib & Seaborn (Visualização de dados)

Jupyter Notebook / Google Colab (Ambiente de desenvolvimento)
